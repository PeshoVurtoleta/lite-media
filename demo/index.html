Flip storm — dispatch N mock events

A mock MQL dispatches N alternating events. Object.is dedupe means the effect fires once per real flip, not once per event. Compare "events dispatched" vs "effect runs" — that's the zero-GC dedupe in action.

Notes

Events alternate true / true / true / false / false / false / true / … — you'll see roughly N/3 effect runs for N events. If you switch to Math.random() < 0.5, the ratio drops to ~50% (approximate flip rate). Both cases prove the same thing: lite-media does nothing between real flips.
