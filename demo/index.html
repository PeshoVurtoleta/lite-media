Reduced-motion rAF gate — the v1.5.0 recipe, live

One effect gates a requestAnimationFrame loop on reducedMotion(). Preference OFF: the bars run. Preference ON: the loop parks — the in-flight frame is cancelled and none is scheduled, so it costs nothing. Flip it back and the loop resumes. Shares the same signal as S1's rm toggle (memoized).
